## 2. Изменения по файлам

### `v12_config.js`
- `COLUMN_COUNT.DASHBOARD: 11 → 9`.
- `DASHBOARD_COLUMNS` → `{ DONE:1, BOM_ID:2, BOM_NAME:3, STATUS:4, TOTAL_POSITIONS:5, COLLECTED_POSITIONS:6, DATE_CREATED:7, DEADLINE:8, MISSING_ITEMS:9 }` (ключи `PROGRESS`, `UPDATED_AT` удалены).
- `HEADERS.DASHBOARD` → 9 заголовков, последний `«Недостающие материалы»`.
- `COLORS`: добавлены `PROGRESS_LOW #F4CCCC`, `PROGRESS_MID #FFF2CC`, `PROGRESS_HIGH #D9EAD3` (палитра градиента статуса).

### `v12_projections.js`
- `v12AggregateBomStates`: элементы `missing` теперь `{ qty, model, expectedDate, code, name }` (было `{ code, name, reason }`). Недостающей считается **не переданная производству позиция с дефицитом > 0** (плюс позиции с ошибкой данных). Счётчики `notOrdered/partial/late/onTime/errors/collected` не изменены — гейт готовности работает как прежде.
- Новые функции: `v12BuildMissingEntry`, `v12BuildMissingItemsText` (формат + сортировка по убыванию срока), `v12DashboardStatusText` (процент + бар), `v12DashboardPercentColor`, `v12InterpolateColor`, `v12HexToRgb`, `v12RgbToHex`, `v12ApplyDashboardStatusColors`; константа `V12_DASHBOARD_BAR_SEGMENTS = 10`.
- `v12RefreshDashboard`: строка = `[done, bomId, bomName, статус-процент+бар, total, collected, дата создания (только дата), крайний срок (только дата), missingText]`; заливка статуса по проценту.
- `v12ApplyDashboardColors` (условное форматирование по тексту) **удалена**; `v12SetupDashboardNotes` теперь кладёт в нотс чистый текст недостач.
- Удалён неиспользуемый `_v12ProjectionUiState`.

### `v12_trigger.js`
- `v12HandleDashboardEdit`: гейт «Выполнено» больше **не читает текст ячейки «Статус»** (там теперь процент) — новая функция `v12IsBomReadyForDone(bomId)` считает готовность из `v12AggregateBomStates` → `v12ComputeBomStatus === READY`.

### `v12_sheet_service.js`
- `V12_ALIGN_CENTER_COLUMNS.DASHBOARD = [1,4,5,6,7,8]` (колонки «BOM», «BOM ID», «Недостающие материалы» — слева).
- Новая `v12MigrateDashboardSchema()`: удаляет колонки «Прогресс» и «Обновлено», приводит заголовок к канону, **скрывает «BOM ID»**, сбрасывает старые правила условного форматирования статуса. Вызывается из `v12EnsureAllSheets`.
- Новая `v12FormatDashboardSheet()`: перенос текста (`WRAP`) + ширина 320px для «Недостающие материалы». Вызывается из `v12EnsureAllSheets`.

## 3. Принятые проектные решения (открытые вопросы из `project_info__46.md`)

1. **Прогрессбар** — текстовые блоки `█████░░░░░` в ячейке «Статус» (нативных data bar в Apps Script нет). Требование «численно указывать процент» выполнено: процент в той же строке.
2. **«Собрано»** — число **позиций**, переданных производству (`PRODUCTION_STATE = RECEIVED`).
3. **Сортировка недостач** — по **ожидаемому сроку поставки (`EXPECTED_DATE`)** по убыванию; позиции без даты — в конце. Форматирование даты — `dd.MM.yyyy`.
4. **Что считать недостающим** — позиции, ещё **не переданные производству**, с дефицитом `> 0` (охватывает «не заказано», «заказано частично», «поставлено частично», «в пути»), плюс позиции с ошибкой данных.
5. **«Дата создания»** — тоже только дата (`dd.MM.yyyy`).
6. **Убрать или скрыть** — «Прогресс»/«Обновлено» **удалены** (логикой не читались), «BOM ID» **скрыт** (удаление сломало бы обработчик чекбокса — ему нужен `bomId`).
7. **Пороги градиента** — 0–50% красный→жёлтый, 50–100% жёлтый→зелёный (`PROGRESS_LOW/MID/HIGH`), линейная интерполяция.
8. **Поле `reason`** — в новом формате «кол-во - модель - срок» больше не выводится.
