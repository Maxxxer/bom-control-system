## 1. Что требуется
1. Добавить в лист **ОТБОРКА** столбец **«Ожидаемый срок поставки»** справа от `ProductionState`.
2. Подсветить каждую строку:

## 2. Текущая схема ОТБОРКИ (12 колонок)
После недавнего удаления «Зарезервировано»: `COLUMN_COUNT.PICKING = 12`, чекбокс на кол. **11**, `UPDATED_AT` на 12. Строку собирает `v12RefreshPicking()`, окраску — `v12ApplyPickingColors(rows)` (сейчас только «На складе» → голубой).

## 3. Целевая схема (13 колонок)
Вставка `EXPECTED_DATE` сразу после `PRODUCTION_STATE`:

| # | Поле | Заголовок |
|---|------|-----------|
| 1-8 | POSITION_ID…REQUIRED_QTY | Position ID…Требуется |
| 9 | AVAILABLE_FOR_PRODUCTION | Доступно для производства |
| 10 | PRODUCTION_STATE | ProductionState |
| **11** | **EXPECTED_DATE** | **Ожидаемая поставка** |
| 12 | CHECKBOX | Отметка получено |
| 13 | UPDATED_AT | Обновлено |

`EXPECTED_DATE` в POSITION_STATE **уже есть** (кол. 14) — новое поле в POSITION_STATE создавать не надо, в отборке оно только отображается.

## 4. Точные правки
**`v12_config.js`**
- `COLUMN_COUNT.PICKING`: `12` → `13`.
- `PICKING_COLUMNS`: `+EXPECTED_DATE: 11`, `CHECKBOX: 11→12`, `UPDATED_AT: 12→13`.
- `HEADERS.PICKING`: вставить `"Ожидаемая поставка"` после `"ProductionState"` → 13 значений.

**`v12_projections.js` → `v12RefreshPicking()`**
- В массив строки добавить `v12FormatDateOnly(r[P.EXPECTED_DATE - 1])` (кол. 11) — функция уже есть в этом файле.
- Окраска: `v12ApplyPickingColors` сейчас видит только метку `PRODUCTION_STATE`. Для новых правил нужны `supplyState`, `expected`, `deadline` из POSITION_STATE. Рекомендую формировать массив цветов прямо в цикле сборки строк (там доступна исходная строка `r`) и передавать его в `v12ApplyPickingColors(rows, colors)`. Логика:
  - `productionState === READY_FOR_HANDOFF` (materialType на складе) → `STOCK` (голубой, как сейчас);
  - иначе (не хватает): `supplyState` `NOT_ORDERED` / `PARTIALLY_ORDERED` → `RED`;
  - `ORDERED`/`PARTIALLY_DELIVERED` + `expected <= deadline` → `YELLOW`;
  - `ORDERED`/`PARTIALLY_DELIVERED` + `expected > deadline` → `ORANGE`;
  - нет даты для сравнения → `WHITE`.
  - Даты разбирать через `v12ToDate`/`v12DateValue` (та же толерантная нормализация, что в `v12DeficitStatusDisplay`). Ширина фона = `COLUMN_COUNT.PICKING` (13).

**`v12_sheet_service.js`** — правок не требует: `v12MigratePickingSchema()` просто перезапишет заголовок на 13 колонок (новая колонка добавляется, legacy-удалять нечего).

**`v12_trigger.js`** — логику менять не нужно: чекбокс/позиция/B1 читаются через `K.CHECKBOX` / `K.POSITION_ID` / `K.BOM_NAME` (жёстких индексов нет).

**`_local_tests/v12_picking_schema_test.js`** — обновить под 13 колонок (CHECKBOX=12, EXPECTED_DATE=11, UPDATED_AT=13; канон заголовка + «Ожидаемая поставка»; C5 — 13 ячеек).
